Official logos for the QR versions go here.

  el-shaddai.png   (or .svg)  -> /el-shaddai
  goa-marathon.png (or .svg)  -> /goa-marathon
  style-bu.png     (or .svg)  -> /business

Then set `logo` for that version in src/data/views.js, e.g.
  logo: '/logos/style-bu.png',

Until a logo is set, the page shows the name as a text wordmark.
Use a transparent PNG or SVG, at least 400 px wide.
